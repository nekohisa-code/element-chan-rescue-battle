# 元素ちゃんレスキューバトル

― 暴走元素ちゃんをすくえ！ ―

理系ねこラボの無料・1人用ブラウザゲーム。元素ちゃんを集めて化学式の組成を完成させ、暴走した仲間を救出します。遊びながら元素記号・元素名・化合物名・化学式に親しめます。

## 公開先

[ゲームで遊ぶ](https://nekohisa-code.github.io/element-chan-rescue-battle/)

公開済みです。自宅PCの起動や同一Wi-Fiへの接続は不要です。

安定版の内容: Prototype 0.16。PC・スマホ対応。タッチ操作で遊べます。

## 遊び方

1. 難易度とサポートを選び、STORYから開始。
2. 作れる化合物候補をタップし、必要な元素ちゃんを選択。
3. 「組成を完成」で攻撃・防御・回復・支援。
4. S → Cl → K → Mn → B → Si → Zn → Sn → Ga → Inを救出し、仲間と次のステージを解放。

元素図鑑118枠・化合物図鑑96種（通常88＋SPECIAL8）、3難易度を搭載しています。元素は組成完成への使用・サポート発動・救出成功で登録し、化合物は実際に作ると登録します。未発見情報は隠れています。未実装の118枠へMASTER画像を一括公開することはありません。図鑑のNEW自動スクロールと並べ替え、各StageのMISSIONで★を集められます。

初級は候補と弱点を表示。中級は未発見の式、上級は式と名前を隠します。中級・上級のおすすめ自動選択は発見済みだけに使用でき、OFFにもできます。弱点に当てると正式情報が解放されます。

C/H/Oを図鑑で発見するとスペシャル合成を研究できます。別ゲージを満たし、8つの研究を進行に応じて解放し、グルコース・エタノール・スクロース・酢酸・クエン酸・カフェイン・尿素・ベンゼンを元素の種類ごとのスタック（×N）で合成。通常手札に大量のカードは並べません。効果はゲーム専用です。

タイプ相性・戦闘効果はゲーム上のルールで、現実の化学的優劣や効能ではありません。実際の反応条件・実験方法を再現する教材ではありません。実物を混ぜたり飲食したりしないでください。

## 保存・音声

進行・救出・仲間・発見した化合物・選択サポートは、そのブラウザのlocalStorageに保存します。アカウント・課金・バックエンドはありません。ローカル版の保存は公開版へ自動移行しません。端末・ブラウザが違う場合も別記録になります。

BGMは初回ON。OFFへ変更した設定は保存して尊重します。Storyには専用の冒険BGMを追加しました。音声は開始操作や音声ボタンのタップ後に再生します。端末の音量・消音設定により聞こえない場合があります。

0.16はPC 1280×900・1600×900、スマホ幅390×844で検証しています。iPhone実機Safariの確認はブラウザ幅検証と区別します。詳細は[0.16ローカル検証報告](docs_internal/LOCAL_VALIDATION_0.16.txt)、[変更履歴](docs_internal/CHANGELOG_0.16.txt)をご覧ください。

0.12・0.13の保存は同じ公開URLで継承します。既存の発見化合物の構成元素と救出済み元素は図鑑へ移行します。未発動サポートの実績は推測で登録しません。「ストーリーだけリセット」は図鑑を保持、「すべてリセット」は進行・発見を消します。どちらも確認画面の「はい」でのみ実行。BGM等の環境設定は保持します。

## 公開・更新方法

GitHub Pages: Deploy from a branch / main / docs。公開用のゲーム一式はdocsに配置し、Python等のサーバー処理は使用しません。

次の安定版が完成したら、別の開発成果物を保護したまま、公開前検証 → docs更新 → git diff・秘密情報検査 → commit → push → Pages反映 → 公開URLで再検証、の順で更新します。通常のゲームURLは固定し、必要に応じてv0.12等のGit tagで履歴を残します。強制pushは使用しません。

## 素材と権利

元素ちゃんの元素材は理系ねこラボのユーザー所有素材、ゲーム用派生画像・背景は本作向け生成素材です。元MASTERは公開Repositoryに含めません。画像・キャラクターIPについて、Repositoryが公開されていること自体は転載・再配布の許諾を意味しません。

音源はLICENSES_AUDIO.txt、画像の扱いはASSET_NOTICE.mdを参照してください。


## Prototype 0.16の改善

Storyを10話へ拡張し、救出で新しい元素・通常レシピが使えるようになります。Story 10で「第1章 COMPLETE」と実救出数 / 118を表示。S・Cl・K・Mn・Bの新しいゲーム画像と、確認済みマイキャラを中心としたPC横長・スマホ縦長の専用タイトルを制作しました。

通常レシピを9種追加。式・名称・個数の[確認レポート](docs_internal/COMPOUND_QC_REPORT_0.16.txt)を収録。スマホSPECIALは2×2、4件ずつ横送りできます。Battleは情報を削らず下端安全余白を確保。NEW図鑑は少し速い順次解放にSEとスキップを追加し、スキップ後も登録・確認済み状態を保存します。

PERFECT SYNTHESIS・ROLE CHAIN・ボス後半・仲間援護・救出Rank・再救出演習・Support独立ゲージは維持。0.15の救出・図鑑・環境設定を安全に継承し、旧Story番号は元素を基準に対応付けます。最終0.16のiPhone実機評価はユーザー確認待ちです。
