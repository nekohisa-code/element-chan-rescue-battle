Prototype 0.14 / 2026-10-05 JST
公開URL: https://nekohisa-code.github.io/element-chan-rescue-battle/

遊び方
STORYから開始。元素の種類と個数をそろえ、化合物の組成を完成させます。
赤△攻撃、青□防御、緑○回復、黄☆支援。Ga→In→Sn→Si→Znを救出します。
初級: 弱点と候補の式・名前を表示し、候補タップで自動選択。
中級: 弱点ヒント、未発見候補は式???・名前表示。発見済みだけ自動選択可能。
上級: 発見前は弱点・候補の式・名前???。発見済みだけ自動選択可能。
中級/上級の「おすすめ自動選択」OFFでは自分で元素を選びます。

図鑑
118元素枠 / 通常79化合物+SPECIAL3種 = 82化合物。
使用、サポート発動、救出で元素を発見。手札出現だけでは解放しません。
NEWは初めて図鑑を開いた際に自動スクロールと光で案内。
複数NEWは「NEWを確認」で次へ。確認済みは再演出しません。
元素: 原子番号順/発見済み優先。化合物: 発見済み/式/種類で並び替え。

スペシャル合成
Support活性化とは別ゲージ。通常合成成功・弱点・連鎖・BREAKで増加。
C/H/Oすべてを元素図鑑に登録すると3種の研究候補が解禁されます。
READYボタン→候補選択→元素1種類につき代表1体が飛ぶ→×N→完成。
グルコース C6H12O6、エタノール C2H6O、スクロース C12H22O11。
大型分子は通常手札へ入れません。効果はゲーム上の創作です。

保存・リセット
同じ端末・ブラウザ・公開サイトのlocalStorageに進行が保存されます。
0.12/0.13の進行と発見を引き継ぎ、新しいフィールドはdefaultで補います。
ローカル版と公開版、異なるブラウザ間で保存は自動共有されません。
ストーリーだけリセット: STORY1へ。図鑑・NEW確認履歴・学習記録は保持。
すべてリセット: 進行・図鑑・弱点・MISSION・SPECIALを初期化。
どちらも確認ダイアログの「はい」だけで実行。「いいえ」は変更なし。
BGM設定とおすすめ自動選択設定は維持します。

ローカル起動
dist/index.htmlを開くかdistを静的HTTP配信。CDN、バックエンド、課金なし。
GitHub PagesではPCを起動せず、同一Wi-FiでなくてもHTTPS URLから遊べます。
音声はSTORY開始などのユーザー操作後に再生。初回BGM ON、OFF設定を尊重。
今回新しい外部素材取得・画像生成は行っていません。LICENSES_AUDIO.txt参照。

科学と創作
Storyは日常語、図鑑は科学情報、戦闘はゲームルールです。
相性・攻撃・防御・回復は実際の化学的優劣や人体作用ではありません。
化学式は組成を表し、同じ分子式の異なる物質もあります。
現実の物質を混ぜたり飲食したりしないでください。

既知の境界
Si/ZnはMASTERコピーにCSS表示マスクを適用。画像自体は無改変。
Znの二人称はローカル承認記録で未確認なので設定・台詞に追加していません。
実機Safariの主観評価と390×844ブラウザ検証は区別します。
通常難易度での全Stageバランス評価とQA救出境界検証も区別します。
SPECIALゲージは各Stageの開始時0。進行途中の戦闘は再読込で再開されません。
